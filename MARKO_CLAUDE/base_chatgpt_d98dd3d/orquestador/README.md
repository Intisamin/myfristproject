# Orquestador central

Flujo: Validadoncio → aprobación humana → Negocioncio → aprobación humana → Ideoncio → producción → revisión humana → publicación → analítica.

Cada etapa deberá conservar proyecto, versión, fuentes, estado, aprobaciones, insumos y resultados. No se publicará contenido sin aprobación.
