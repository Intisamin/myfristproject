# Autorizaciones y seguridad

El flujo distingue **cinco decisiones**: aprobar banco de ideas; aprobar calendario/guion; autorizar gasto de proveedores; aprobar **el MP4 final exacto**; autorizar **la publicación** de ese MP4 para redes y fecha concretas.

- No asumir aprobaciones entre Reels ni versiones del mismo Reel.
- Asociar cada aprobación al hash SHA-256 del archivo revisado; cambiar portada/audio/video exige revisar de nuevo.
- No consumir créditos de HeyGen, Magnific ni otras herramientas sin autorización humana para ese gasto concreto.
- No invocar Descript Underlord sin autorización específica.
- Antes de publicar, consultar publicaciones previas por `content_id`, proveedor y redes para no duplicar.
- Nunca copiar secretos, información de clientes, enlaces firmados ni expedientes comerciales al GitHub público.
- Los guiones del lote de noviembre aprobados en P0.2 permanecen literales y **fuera de esta vista pública**.
- Prohibido declarar `PUBLISHED` a partir de un `PENDING`: consultar estados de las tres plataformas.
- Nombre comercial en portada/copy/cuenta: **Categorización Dental**, no MARKO.
