# MARKO-AGENTE

Repositorio general de MARKO: **DESCUBRE → CONECTA → CRECE**.

## Organización
- `01-DESCUBRE/`: Validadoncio y Negocioncio, contratos, plantillas y pruebas anonimizadas.
