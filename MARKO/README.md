# MARKO-AGENTE

Repositorio general de MARKO: **DESCUBRE → CONECTA → CRECE**.

## Organización
- `01-DESCUBRE/`: Validadoncio y Negocioncio, contratos, plantillas y pruebas anonimizadas.
- `02-CONECTA/`: Ideoncio, Libretoncio, Recursoncio, Produccioncio, Editoncio y Revisioncio.
- `03-CRECE/`: Publiconcio y Analiticoncio.
- `orquestador/`: flujos, aprobaciones y transferencia entre agentes.
- `documentacion/`: arquitectura, decisiones y changelog.

**Privacidad:** este repositorio es PÚBLICO. No incluir Excel de clientes, chats, información financiera confidencial, datos personales ni material no autorizado. El historial anterior de Git no se borra por cambiar los archivos visibles.
