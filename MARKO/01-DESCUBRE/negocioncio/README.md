# Negocioncio

Versión de referencia aprobada: **1.8.0**.

Trabaja desde el nicho validado. Analiza en profundidad cliente, problema externo verificable → causas → efectos → consecuencias → dolor interno (cuando hay evidencia) → solución; compara alternativas y ventajas competitivas demostrables. Diseña proceso, catálogo, precios, estrategia comercial y brief para Ideoncio. Entrega **PDF Maestro visual** solo con contenidos confirmados; investigación e hipótesis permanecen en expediente interno.

No reemplazar un plugin existente sin verificar identidad y permisos. El archivo completo `SKILL.md` está en el respaldo descargable, pendiente de sincronizar aquí.
